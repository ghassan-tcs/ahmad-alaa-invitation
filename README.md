# بطاقة دعوة — أحمد وآلاء

صفحة دعوة عربية لحفل عقد القران. **HTML + CSS + JS فقط** — بلا قاعدة بيانات وبلا خادم
وبلا خطوة بناء. تصلح للرفع مباشرةً على GitHub Pages.

---

## 🔴 ثلاثة أشياء غيّرها قبل الإرسال

كلها في **`data/config.json`**:

| المفتاح | القيمة الحالية | ما يجب |
|---|---|---|
| `التاريخ_والوقت` | `2026-10-15T19:00:00` | التاريخ الحقيقي — **يقود العدّاد وملف التقويم** |
| `التاريخ_المعروض` · `الوقت_المعروض` | نصّ مؤقّت | ما يُكتب على البطاقة |
| `المكان` · `العنوان` · `رابط_الخريطة` | قاعة الأندلس (مؤقّت) | القاعة الحقيقية ورابط خرائط جوجل |

بقية القيم (الاسمان · الآية · الكلمة الختامية) في الملف نفسه وجاهزة.

---

## أسماء المعازيم

في **`data/guests.json`**. كل ضيف سطر واحد:

```json
{ "id": "7", "prefix": "السيد", "name": "عمر الخطيب", "suffix": "وعقيلته الكريمة" }
```

- `id` — يجب أن يكون **فريداً**، وهو ما يظهر في الرابط
- `prefix` و`suffix` اختياريان (اتركهما `""` إن لم تُردهما)
- أي مفتاح يبدأ بـ`_` يتجاهله الموقع — استعمله للملاحظات

---

## الروابط

| الشكل | المعنى |
|---|---|
| `index.html?g=3` | الضيف صاحب `id = 3` من ملف الضيوف |
| `index.html?name=عائلة%20الخطيب` | اسم مباشر ليس في الملف — لدعوة عاجلة |
| `index.html` | بلا اسم ⟸ «ضيفنا الكريم» |

**لا تكتب الروابط بيدك.** افتح **`links.html`** — يعرض كل ضيف مع رابطه الشخصي وثلاثة
أزرار: نسخ · فتح · إرسال بواتساب. وحقلُ العنوان في أعلاها يضبط النطاق تلقائياً حسب مكان
فتحك للصفحة.

## التشغيل محلياً

الصفحة تقرأ ملفَّي JSON، والمتصفح **يمنع ذلك عند فتح الملف بنقرة مزدوجة** (بروتوكول
`file://`). لا بدّ من خادم:

```bash
# XAMPP يخدمه أصلاً إن كان المجلد داخل htdocs
http://localhost/ahmad-alaa-invitation/

# أو خادم مؤقّت بأي أداة
php -S 127.0.0.1:8899
python -m http.server 8899
```

على GitHub Pages لا تظهر هذه المشكلة إطلاقاً — الموقع يُخدَم عبر https.

## الرفع على GitHub Pages

```bash
git init && git add -A && git commit -m "بطاقة دعوة"
git branch -M main
git remote add origin https://github.com/<حسابك>/<المستودع>.git
git push -u origin main
```

ثم في المستودع: **Settings ⟵ Pages ⟵ Source: Deploy from a branch ⟵ main / (root)**.

يصير الرابط: `https://<حسابك>.github.io/<المستودع>/`
ورابط الضيف: `https://<حسابك>.github.io/<المستودع>/index.html?g=1`

> المشروع ملفات ثابتة بحتة — لا يحتاج Jekyll ولا أي إعداد بناء.

## تفاصيل تقنية

- **الخطوط**: Aref Ruqaa (الأسماء) · Amiri (النصّ) · IBM Plex Sans Arabic (الأرقام والأزرار) — من Google Fonts.
- **اسم الضيف يُكتب بـ`textContent` لا `innerHTML`** — فأي محتوى في الرابط يُعرض نصّاً ولا يُنفَّذ.
- **ملف التقويم** (`.ics`) يُولَّد في المتصفح بـ`Blob` — بلا خادم.
- **الحركة** تحترم `prefers-reduced-motion`، وكل شيء مرئي في الإطار الأول.
